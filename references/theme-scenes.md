# 主题镜头契约

系列复用颜色、粒子材质、透视、轨迹、字体、混音和时间锚点；每期重新创作视觉因果链。原《合拍》镜头只在显式选择 `hepai-scenes.js` 时使用。

## 先设计，再构建

助手根据主题自动完成，无需让用户填写配置：

1. 明确主题要解释的关系，例如《幸存者偏差》的“选择性可见—遗漏—补回样本”。
2. 为每段写出 `visual`（画面主体）、`action`（主动作）、`meaning`（动作解释的信息）。一个镜头可覆盖多句字幕。主动作要在关闭字幕后仍然看得见。
3. 在主题JS中实现形态、运动、相机和必要的轨迹提示。公共粒子池保留身份并完成形态插值；主题模块不要用整幅图像叠化冒充形变。
4. 分别查看四段动态预览与《合拍》画风参考：材质相似、主要视觉事件不同。记录具体观察，不能仅凭文件不同、镜头ID不同或像素差通过主题验收。
5. 预览合格后渲染，并让未参与制作的审片者检查最终MP4的技术和主题表达。

## 配置

在已有主题文案配置中，必须提供：

```json
{
  "scene_module": "my-topic-scenes.js",
  "scenes": [
    {
      "id": "observation_window",
      "start": 0,
      "end": 6,
      "morph": 1.05,
      "visual": "狭窄观察窗口和经过它的记录",
      "action": "窗口中的记录保持明亮，窗口外的轨迹变暗",
      "meaning": "观众只看到总体的一部分"
    }
  ]
}
```

示例只列一镜，完整配置必须连续覆盖正片0–90秒。以上时间均为正片秒，成片时间加3。`morph`为入镜形变时长，须大于0且不超过该镜时长。`kind: "anchor"`仅在本期确实需要粒子拼成锚词时添加，其他镜头不指定。33.5秒的可读大字由公共文字层保证，并不要求每期都把粒子聚成相同字卡。

`cover_scene`可选，指定本主题已有镜头作为封面背景，正片开始时连续变形至首镜；未指定时沿用首镜。

`diagram_labels`可选，每项为`text/start/end/x/y`；时间为正片秒，位置为1920×1080画布坐标。标签与研究事实卡不应互相遮挡。字幕时表由构建器保留，镜头时表完全来自`scenes`。

## 主题JS接口

模块加载在公共绘制器之后，必须设置：

```javascript
window.PARTICLE_SCENE = {
  sceneIds: ['observation_window'],
  point(q, scene, t) {
    // Return [worldX, worldY, worldZ, opacity, colorIndex].
    // colorIndex: 0 copper, 1 ice blue.
  },
  camera(t) { return {yaw: 0, scale: 1, cy: 405}; },
  decorate(t, previous, current, morphProgress) {
    // Optional guide strokes. Main subjects remain in the particle pool.
  }
};
```

`point`必须为每个声明的镜头返回有限数值；未知镜头不得返回通用旧动画。`q`含固定身份`k`、固定随机值`u/v/w/a`、分组`g`和粒径`size`。以q与时间计算运动，不使用新随机数、计时器或上一帧状态，保证跳转和逐帧导出一致。

世界坐标原点投影到画面中心附近。透视距离1120；请避免z接近−1120。公共辅助函数为`clamp/smo/mix`、`project(point,t)`、`line(screenPoints,color,width,alpha)`、`glow(x,y,r,colorIndex,alpha)`及常量`TAU/cs`。`camera`和`decorate`可省略。

相机与装饰变化也应由时间直接计算；转场时主粒子由公共绘制器在前后形态之间连续插值。保持字幕区暗部，避免用轨迹覆盖文字。

## 预览与验收

`preview.py --motion`生成四段带混音的960×540动态预览：成片3–8、32.8–37、49–54、85–90秒；同时保留全分辨率关键帧与技术检查。这些窗口用于早期检查开场、高潮、解释段、结尾，不规定该窗口必须出现什么形状。

记录两项独立结论：

- 风格：颜色、发光、粒子层次、透视和字体是否属于同一系列。
- 主题：画面对象和动作是否解释本期信息；与前片相比，实际改变了哪些主要视觉事件；哪些只是共同的系列元素。

不要用自动“重复度百分比”代替审美判断。若只换文案、速度、随机种子、旋转方向或镜头顺序，退回镜头设计。
